# Phase 1: Design system components

**Status:** not started
**Design:** `to-do.pen`, frame "Components"

## Goal
Every reusable UI piece exists as a SwiftUI component, driven by tokens.

## Scope
### Tokens
- [ ] Colors: bg, surface, border, text-primary/secondary/muted, accent, accent-soft, on-accent, danger
- [ ] Category chip colors: work, personal, shopping (bg + fg)
- [ ] Fonts: Fraunces (heading), Bricolage Grotesque (body), Outfit (UI), Caveat (accent), DM Mono
- [ ] Radii: radius-md 16, radius-pill 999

### Components (in the .pen library)
- [ ] Category Chip
- [ ] Task Row
- [ ] Task Row Done
- [ ] Primary Button
- [ ] Add Task Input
- [ ] Filter Pill

### Components seen on screens, not yet in the library
- [ ] Save Button
- [ ] Category Option
- [ ] Quick Add Input
- [ ] Undo Toast

## Out of scope
- Business logic, navigation, persistence

## Done when
- A preview screen renders every component.
